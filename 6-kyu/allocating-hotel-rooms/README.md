<h2><a href=https://www.codewars.com/kata/6638277786032a014d3e0072/train/javascript target="_blank">Allocating Hotel Rooms</a></h2><h3>6 kyu</h3><h4 id="task">Task</h4><p>Allocate customers to hotel rooms based on their arrival and departure days. Each customer wants their own room, so two customers can stay in the same room only if the departure day of the first customer is earlier than the arrival day of the second customer. The number of rooms used should be minimized. </p><h4 id="input">Input</h4><p>A list or array of <strong>n</strong> customers, 1 ≤ <strong>n</strong> ≤ 1000. Each customer is represented by (arrival_day, departure_day), which are positive integers satisfying arrival_day ≤ departure_day. </p><h4 id="output">Output</h4><p>A list or array of size <strong>n</strong>, where element <strong>i</strong> indicates the room that customer <strong>i</strong> was allocated. Rooms are numbered <strong>1,2, ..., k</strong> for some <strong>1 ≤ k ≤ n</strong>. Any allocation that minimizes the number of rooms <strong>k</strong> is a valid solution. </p><h4 id="example">Example:</h4><p>Suppose customers is [(1,5), (2,4), (6,8), (7,7)]. <br>Clearly customers 1 and 2 cannot get the same room. Customer 3 can use the same room as either of them, because they both leave before customer 3 arrives. Then customer 4 can be given the other room. <br>So any of [1,2,1,2], [1,2,2,1], [2,1,2,1], [2,1,1,2] is a valid solution.</p><p>NOTE: The list of customers is not necessarily ordered by arrival_time.</p><h5 id="source-cses">Source: <a href="https://cses.fi/problemset/task/1164" data-turbolinks="false" target="_blank">CSES</a></h5><h5 id="related-kata">Related kata:</h5><p><a href="https://www.codewars.com/kata/5e1b37bcc5772a0028c50c5d" data-turbolinks="false" target="_blank">Minimum number of taxis</a> is a harder version, because the lists are bigger.</p><p><a href="https://www.codewars.com/kata/5b9cf881d6b09fc9ee0002b1" data-turbolinks="false" target="_blank">The Hotel with Infinite Rooms</a> <br><a href="https://www.codewars.com/kata/5ca8cb15d7f22c002a805b29" data-turbolinks="false" target="_blank">Is room reserved?</a><br></p>
